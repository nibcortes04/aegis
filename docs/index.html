Core Capabilities

Built for High-Velocity Engineering

⚡

Smart Auto Mode

Zero approval lag for safe tools (reads, searches, in-workspace edits, tests). Fails closed and requests human approval for critical commands (rm -rf, git push -f, docker rm, dd).

🔔

Tab Bell & Notifications

Direct \a ASCII 7 emit to /dev/tty for native bell icons in KDE Konsole and Orca tabs. Auto-dismissing desktop notifications (4s) via notify-send with int:transient:1 to prevent sticky alerts.

📊

Claude Code Statusline

Real-time reasoning effort (🧠), live Git diff line counter (+X -Y), session title from SQLite database, context bar with color thresholds (>70% yellow, >90% red), and 5h/7d quota tracking with local reset time.

📱

Android PWA & Cloud Sync

Seamless remote control via official Google Antigravity Remote PWA (antigravity.google). Full workflow to pair, monitor, and resume sessions from Android phones or tablets.

🌳

Git Worktree Workflow

Built-in scripts (scripts/dev-worktree.sh) to isolate features, fixes, and autonomous bot contributions without polluting main or dirtying working trees.

🤖

Bot & Human Ready PRs

Standardized PR template and CI gate designed for both human engineers and autonomous agents (Codex, Claude, AGY) to contribute with zero merge regressions.

🌐

Cross-Platform (Linux, macOS, Windows)

Native adaptors for KDE Konsole, Orca, macOS AppleScript/terminal-notifier, and Windows 10/11 WinRT Toast notifications. Dynamic path resolution without hardcoding.

🖥️

Surface Aware (CLI, IDE, Desktop App)

Detects whether AGY is executing inside a pure terminal, the Antigravity IDE (VS Code), or Antigravity 2.0 (Electron App), tailoring hooks and security boundaries accordingly.

DevOps & Collaboration

Git Worktree Isolation Standard

No more stash conflicts. Every feature, bugfix, or autonomous bot PR gets its own isolated tree.

# 1. Create an isolated worktree for a new feature
$ ./scripts/dev-worktree.sh new feat/smart-filtering

# 2. Develop & run tests inside the isolated worktree
$ cd worktrees/feat/smart-filtering
$ python3 -m unittest discover -s tests -p "test_*.py"

# 3. Clean up when merged into dev
$ ./scripts/dev-worktree.sh remove feat/smart-filtering
Getting Started

Quick Installation

Option A: Universal Python (All OS)

git clone https://github.com/n-n/agy-powerpack.git ~/.gemini/antigravity-cli/plugins/agy-powerpack
python3 ~/.gemini/antigravity-cli/plugins/agy-powerpack/install.py

Option B: Linux / macOS / Windows Native

# Linux / macOS:
~/.gemini/antigravity-cli/plugins/agy-powerpack/install.sh

# Windows (PowerShell):
powershell -ExecutionPolicy Bypass -File .\install.ps1

Option C: Antigravity CLI Plugin Manager

agy plugin install ./agy-powerpack
agy plugin validate agy-powerpack
