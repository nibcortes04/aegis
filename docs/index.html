Core Architecture

Engineered for Autonomous Reliability

Combining the best patterns from across the agentic engineering frontier.

⚡

Smart Auto Mode

4-tier graduated trust profiles (audit, workspace-safe, full-developer, subagent-worker). Sub-10ms deterministic filtering eliminates prompt lag while securing the workspace.

🛡️

Two-Factor Safety Gate

Irreversible commands (rm -rf, mkfs, docker stop/rm, drop database) trigger a mandatory 2-step verification ledger, protecting host and VPS production containers.

📊

Claude Code Statusline

Live Git diff lines (+X -Y), active reasoning effort (🧠), session title from SQLite, visual context usage bar with threshold warnings, and 5h/7d quota tracking with local reset timestamps.

🔔

Multi-Session Tab Bell Telemetry

Emits ASCII 7 \a to /dev/tty to light up the 🔔 icon in terminal tabs. Enforces 4-5s auto-expiring desktop toasts without stacking or freezing on KDE Plasma / Linux.

🤖

Multi-Agent Catalog

5 specialized subagents (researcher, worker-backend, worker-frontend, qa-tester, reviewer-bot) operating across isolated Git worktrees without polluting context.

📱

Android PWA Continuity

Seamless remote pairing via Google Antigravity Remote PWA (antigravity.google). Approve tools, monitor build logs, and resume sessions from Android phones or tablets.

Anywhere Continuity

2
